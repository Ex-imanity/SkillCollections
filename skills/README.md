# Skills

本目录包含可独立分发的 Agent Skills。每个子目录都是一个完整安装单元，入口文件
为 `SKILL.md`。

安装某个 Skill 时复制整个子目录，不要把多个 Skill 合并成一个目录，也不要删除其
`references/`、`scripts/`、`assets/` 或 `tests/`。
