# Changelog — case-lite-lark

## 0.2.1 - 2026-10-19

- 修复首次本地使用被默认视为平台环境的问题，新增 auto 诊断状态和运行位置确认指引。
- 未确定运行环境时先确认本地/平台，不在未知应用上下文发起登录或创建新 App。
- 缺少 CLI 时同时提供本地安装和平台预置指引；补充旧 case-lite 迁移与全新成员接入说明。

## 0.2.0 - 2026-10-19

- 核对私有平台仓库 cd6dd94：原 24 个文件与本仓库 0.1.0 一致，沿用其已验证的平台基线。
- 新增本地一次性接入脚本，导入内部提供的已有 App；不创建新应用、不覆盖其他 profile。
- 同一应用已配置时直接复用；配置损坏、同名不同 App 或初始化状态未确认时中止。
- 本地接入按 CLI 配置目录互斥，支持复用带点号或中文的现有 profile。
- 本地模式持久化无凭证的模式/profile 设置，授权、目录、正文和媒体均使用同一 profile。
- 平台模式保留绑定的凭证来源和应用选择；配置错误提供对应恢复指引，不引导新建应用。
- 增加本地/平台分发与用户授权说明、占位配置示例和接入回归场景。

## 0.1.0 - 2026-10-19

- 新增独立的 lark-cli 云端版 Skill，不修改原始 case-lite。
- Docx/Wiki/原生 Markdown 子文档发现、目录、手动选章和原文落盘。
- 复用 FeishuMCP 3.4.0 的纯 Python BlockProcessor，保留表格、代码和媒体锚点。
- 显式 user 身份、完整分页校验、树形文档顺序、版本/哈希变化检测、重叠章节合并。
- 修复上游长单元格截断、重复文本删除、链接丢失；跨非 Docx 节点发现后代，显式报告 iframe/附件。
- 图片/画板通过 CLI 下载，输出绝对路径供 Agent Read；失败与内嵌资源缺口显式记录。
- 保留场景分层复核、完整用例审核、可选自检、迭代归档和人工确认。
- 内置搬山参考读取及写回，增加确认参数、空用例检查和业务内容读回核验。
- 提供离线测试与 Skill 行为评估场景；真实云端验收由平台执行。
