# Skill maintenance guides

These guides describe changes to the skills themselves. They belong to the
source repository and are not required when an installed skill performs a task.

- [Case-design strategy evolution](case-design-strategy-skill.md)
- [Preflight domain-adapter template](deep-task-preflight.md)
- [Repository-code-style evidence and validation maintenance](repository-code-style.md)

Keep unit checks in `tests/<skill>/`, qualitative evaluations in `evals/<skill>/`,
and runtime instructions/dependencies in `skills/<skill>/`.
